# Security and Privacy

- This starter release uses fictional local demo data and does not sign in to Instagram.
- Never request or store an Instagram password.
- Do not bypass private-account controls, login walls, rate limits or platform restrictions.
- Use HTTPS and least-privilege permissions for future integrations.
- Keep secrets in OS-backed credential storage; never log access tokens.
- Provide clear source labels, retrieval times and completeness states.
- Allow users to delete local research data and snapshots.
- Do not infer gender, ethnicity, religion or other sensitive attributes from profile imagery,
  names, usernames or comments.
- Retain only information necessary for the user's lawful research purpose.
