# UI / UX
* **Look**: deep navy `#0B1020`, sidebar `#0D1425`, cards `#11182A`, accents purple `#8B5CF6` / cyan `#22D3EE`; radial purple/cyan backdrop; glass, solid or minimal cards; light theme; 6 accent colours; custom wallpaper with adjustable darkening; compact density; compact (icon-only) sidebar; animations toggle.
* **Navigation**: collapsible sidebar by section (Overview, Instagram experience, Tracking, Engagement, Monitoring, Tools, System) + command palette (Ctrl+K) + shortcuts Ctrl+1…7, Ctrl+R refresh, F11 full-screen.
* **Instagram experience**: story rings (gradient = unseen, grey = seen), post cards, profile grid with reel/carousel glyphs, post viewer (←/→ posts, ↑/↓ carousel, F full-screen), story viewer (←/→, Space pause, Esc).
* **Honesty UI**: demo banner, source chip, availability chips, "N of M loaded", "first detected" wording.
